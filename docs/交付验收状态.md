更新：2026-11-07。当前版本：0.3.0-rc.3。目标仍是完整开发和发行；不能把清单功能或本机负例验证当作跨平台检测产品已交付。

## 已完成

- 真实复现并修复 4→1：按 Windows 端口属性排除内置摄像头、蓝牙等 3 个设备。Xiaomi 15 和换上的 Galaxy S21 5G 均实测为 1 个外接连接，480 Mbps。
- 已确认外接数据连接立即得到普通文件传输建议；不会从当前速度推断线材最高速度，也不会从手机品牌推断功率。
- Windows 自有 UCSI 读取器实机返回与微软工具一致。当前电脑 UCSI 1.2、2 个连接器、可选能力为 0，不能提供线材额定规格；设置已恢复、控制器正常。
- 应用内兼容性检查、临时启用与恢复、恢复记录、按电脑与固件隔离的结果缓存、控制器属性和芯片身份的独立解析与保存。
- 故障模拟覆盖提权取消、超时、日志损坏、部分恢复失败、恢复重试和写入失败；无实际系统改动。
- 名称、照片、规格补录、清单、七类用途、HTML/CSV/JSON 导出、JSON 恢复、重启持久化。
- 主清单损坏或丢失时，在界面恢复上一版备份或选择 JSON；验证备份后才恢复，损坏原件另存。恢复后照片和重启持久化已在 RC2 打包版验证。
- Windows PowerShell 5.1 实机普通扫描通过；本机用时约 0.95 秒。无需用户另装 PowerShell 7。
- RC3 在 Windows 上 46 项自动测试全部通过；两种 Mac 架构分别通过 45 项，跳过 1 项 Windows 专用测试。三平台 TypeScript、生产构建、打包和打包后档案流程通过。依赖版本未变；此前官方 npm 审计为 0 项漏洞。
