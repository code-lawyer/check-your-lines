- 真实复现并修复 4→1：按 Windows 端口属性排除内置摄像头、蓝牙等 3 个设备。Xiaomi 15 和换上的 Galaxy S21 5G 均实测为 1 个外接连接，480 Mbps。

- 应用内兼容性检查、临时启用与恢复、恢复记录、按电脑与固件隔离的结果缓存、控制器属性和芯片身份的独立解析与保存。

- 名称、照片、规格补录、清单、七类用途、HTML/CSV/JSON 导出、JSON 恢复、重启持久化。
- 主清单损坏或丢失时，在界面恢复上一版备份或选择 JSON；验证备份后才恢复，损坏原件另存。恢复后照片和重启持久化已在 RC2 打包版验证。
- Windows PowerShell 5.1 实机普通扫描通过；本机用时约 0.95 秒。无需用户另装 PowerShell 7。
- 41 项自动测试、TypeScript 与生产构建通过。开发版完整清单流程通过。官方 npm 审计 0 项漏洞。
