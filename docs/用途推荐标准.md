# 线材档案与用途推荐标准

版本：2026-11-06.1。对应 Cablewise 0.2。规则由 `shared/recommendations.mjs` 执行，界面内「用途标准」展示同一份表。

这是产品内置的整理规则，不是行业认证标准、实测质量结论或所有设备的最低要求。30W、60W、5Gbps、5V/1A 是本工具默认的筛选门槛。输出优先用途与其他候选用途；一根线可以有多个用途。

| 用途 | 优先选择条件 | 判断边界 |
| --- | --- | --- |
| 主力手机充电 | USB-C 双头、标称功率至少 30W | 仍需匹配手机型号、协议、充电器；不推断品牌私有快充。低于门槛不代表不能充电。 |
| 笔记本充电 | USB-C 双头、标称功率至少 60W；超过 100W 还要明确 EPR 声明 | 对照电脑实际目标功率；60W 不代表能满足所有笔记本。 |
| 普通文件传输 | 已确认可传数据 | USB 2.0 也属于数据线；当前通信成功不证明最高速度。 |
| 高速硬盘 / 大文件传输 | 可传数据，明确声明速度至少 5Gbps | 不把当前协商速度当成线材最高规格；实际复制速度还取决于端口和设备。 |
| 鼠标 / 键盘充电 | 接口已知、额定至少 5V/1A | 仅作为满足 5V/1A 以内设备要求的候选，不要求高速数据。接口和设备要求需要核对。 |
| 鼠标 / 键盘有线连接 | 已确认具备数据能力 | 设备本身也必须支持有线通信；仅供电线不满足。 |
| 出行多用途主力 | USB-C 双头、至少 60W、数据声明至少 5Gbps | 不由此推断显示输出、雷电、私有快充；超过 100W 的功率声明仍校验 EPR。 |

## 推荐顺序

多用途条件成立时优先显示「出行多用途主力」；大功率且传输较慢的线优先安排笔记本充电；其他已知高速数据线优先安排高速传输；再考虑手机、小设备充电及普通传输。全部符合的用途仍可展开查看。

没有规格时保持「用途待确认」，不默认推荐给鼠标、键盘。存在检测警告时暂停自动推荐。模糊的 USB4 20/40Gbps 编码不强行选取最高值。仅凭功率或品牌名不作私有快充认证。

## 线材档案

- 每根线有独立档案编号、自定义名称、一张可替换的照片、存放位置和备注。
- 可以将已检测连接确认登记，也可以手动录入。用户确认之前，系统设备连接不自动变成实体线材档案。
- 登记后自动汇总到「我的线材」。不会只凭端口编号合并或覆盖另一根线；重插与换端口不自动声称识别出同一根物理线材。
- 原检测字段保留。包装、官网等补录规格写入独立字段并注明来源；照片仅用于辨认，不推测规格。
- 桌面版写入应用数据目录 `cable-catalog.json`，原子替换并保留上一版 `.bak`。写入成功后才更新界面；损坏或无法读取时阻止空清单覆盖。
- 浏览器预览使用 IndexedDB。首次打开会尝试迁移同一用户配置中旧版的本地快照；旧工作目录源文件未被迁移操作删除。
- 本版最多 500 条。照片仅接收 JPG/PNG/WebP，最大输入 15MB；转为最长 960px 的 JPEG，清除原文件元数据并控制存储体积。照片离线保存。

## 导出与恢复

| 格式 | 用途 | 照片 |
| --- | --- | --- |
| HTML 图文清单 | 单文件离线查看、分享、浏览器打印或另存为 PDF | 内嵌照片 |
| CSV 表格 | 表格软件筛选和整理；UTF-8 BOM；防止名称被解释为公式 | 不嵌入照片，表格注明这一点 |
| JSON 完整备份 | 保存全部档案、照片、补录来源、演示标记和推荐结果 | 内嵌照片，可导入 |

导入只追加未存在的档案编号，重复编号跳过，不静默覆盖现有档案。导入后按当前内置规则重新计算推荐。旧版本导出的 Cablewise JSON 记录也可导入。演示记录在保存、导出、导入后均保留演示标记。

## 事实依据与产品推断

- [USB-IF 线材标识指南](https://usb.org/sites/default/files/usb_type-c_cable_logo_usage_guidelines_jan26_final.pdf)：功率与数据速率分别标识；USB 2.0 的 60W / 240W 线仍可为 480Mbps。用于支持充电和传输分开判断。
- [苹果 240W 充电线规格](https://www.apple.com/shop/product/myqt3am/a/240w-usb-c-charge-cable-2-m)：高充电功率与 USB 2 数据能力可以同时存在。用于检验「高功率不自动推荐高速传输」。
- [苹果 USB-C 连接说明](https://support.apple.com/en-us/105099)：充电、数据与设备组合有关；USB 3 的高速用途要求匹配的数据线。未将机型列表固化成通用规则。
- [Logitech MX Master 3S 官方使用说明](https://support.logi.com/hc/en-nz/articles/8335872639767-Getting-Started-MX-Master-3S-for-Mac)：其 USB-C 口用于充电，通信说明使用无线连接。用于说明小设备充电与有线通信必须分别判断；不将该设备特征概括为所有键鼠。

以上来源支持能力维度和边界；具体整理门槛及默认排序是产品设计选择。
