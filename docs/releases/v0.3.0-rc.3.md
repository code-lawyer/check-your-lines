# Cablewise 0.3.0-rc.3 预发行说明

线知用于辨认、记录和选用自己的线材。此版本是未签名的候选版，尚未完成跨平台实物线材验收。

## 功能

- 自定义线材名称、照片、位置、备注和已知规格，离线保存。
- 自动汇总清单，导出 HTML 图文清单、CSV 表格与含照片的 JSON 备份。
- 内置七类用途标准，按已有证据推荐主力手机充电、普通或高速传输、键鼠充电等用途。
- Windows 区分外接连接与内置 USB 设备，修复一根手机线被统计为四个连接的问题。
- 主清单损坏或丢失时，支持恢复上一版自动备份或选择 JSON；校验后才替换，并保留损坏原件。
- macOS 在系统未返回线材记录时显示空结果与说明，修复空输出导致 XML 解析失败的问题。
- Windows 便携版兼容系统临时目录的短路径别名，避免正常页面被误判为未知调用来源；仍只接受本应用主窗口的界面请求。

## 下载与验证

Windows x64 便携 EXE 无需安装。macOS arm64 / x64 DMG 为开发验收包，未签名、未公证，尚未验证从下载到正常安装的完整流程。

每个应用文件提供 SHA-256；Windows 包另有内容、版本资源与签名状态检查报告。源码包从发行标签生成，不包含本机用户档案、诊断报告或测试照片。

[本次 GitHub Actions](https://github.com/code-lawyer/check-your-lines/actions/runs/42377422658) 的 Windows x64、macOS arm64 / x64 三项任务全部通过。Windows 46 项测试通过，Mac 每种架构 45 项通过、1 项 Windows 专用测试跳过。具体已完成与未完成项见 [VALIDATION.md](../../VALIDATION.md)。云端测试覆盖构建、启动、档案、照片、导出、恢复和重启，不代表实物线材读取成功。

## 已知边界

- 当前连接速度不等于线材额定最高速度；不能从手机名称或 480 Mbps 推断额定功率。
- 额定功率、电压、电流与芯片信息能否读取，取决于电脑接口、固件和线材。本机 Windows 固件未开放相关信息。
- 不测量线阻、压降、发热、实际承载能力，不给出质量评分；品牌私有快充仍需匹配设备、充电器和线材。
- 正式应用管理员诊断的完整实测、支持规格读取的 Windows 硬件正例、Mac 实物线材、签名和公证仍待完成。

版本发布不改变上述验收状态。旧版清单可以继续使用；建议先导出 JSON 备份。
